# 自测报告 — 面试能力提升平台（前端）

## 1. 硬性门槛

本项目通过标准的 Docker Compose 编排方式进行交付，执行 docker compose up --build -d 即可在本地一键启动全部服务。Nginx 容器作为静态资源服务器对外暴露八零八一端口，浏览器访问 localhost:8081 可直接进入平台首页。多端口环境下不存在端口冲突风险，Dockerfile 采用多阶段构建策略，基础镜像选用 node:20-alpine 与 nginx:alpine，均原生支持 ARM64 和 AMD64 架构，Apple Silicon 与 x86 机器均可正常构建运行。

## 2. 交付完整性

项目严格围绕 Prompt 所定义的三大核心模块展开实现。题库展示模块提供了包含三十二道面试题目的完整题库，涵盖前端、后端、算法、系统设计、行为面试五大分类，每个难度梯度至少八道题目，支持分类筛选、难度筛选、关键词搜索与分页浏览。模拟面试模块实现了面试配置、逐题作答、倒计时、评分回顾的完整流程闭环。学习记录模块包含学习日历热力图、分类掌握度统计、刷题记录时间线、面试历史记录与收藏夹管理。全部十一条路由均可正常访问，不存在空白页或未实现的页面。

## 3. 工程架构

项目采用 Vue 3 Composition API 配合 script setup 语法糖，搭配 Pinia 状态管理和 Vue Router 路由管理，形成清晰的 MVVM 分层架构。源码目录按功能模块划分为 views、components、stores、mock、utils 五个核心目录，组件层进一步拆分为 layout 和 common 两个子目录。路由配置支持懒加载与代码分割，Vite 构建配置通过 manualChunks 将 Element Plus 和 Vue 核心库独立分包。Mock 数据层通过 Axios 拦截器实现，与业务组件完全解耦，未来切换真实后端接口只需移除拦截器配置即可。

## 4. 工程细节

项目提供统一的 Logger 工具模块，支持 debug、info、warn、error 四个日志级别，生产环境自动过滤低级别输出，禁止散落的 console.log 调用。Axios 请求封装统一处理鉴权 Token 注入与错误响应拦截，Store 层全部异步操作均包裹在 try-catch 中并通过 Logger 记录异常。日期格式化统一使用 dayjs 库，输出格式固定为 YYYY-MM-DD HH:mm:ss。表单提交前执行非空校验，面试会话页在无有效 Session 时自动重定向到配置页。所有可交互按钮均绑定真实功能逻辑，不存在无响应的死按钮或指向井号的空链接。

## 5. 需求适配

项目精准实现了 Prompt 所描述的面试能力提升平台前端部分。题库展示满足了分类筛选、难度筛选、搜索、分页、题目详情、参考答案折叠展示、答题笔记编辑保存、收藏标记等全部子需求。模拟面试满足了面试类型选择、难度配置、题量选择、计时开关、逐题作答、进度展示、跳过、评分、答案对比回顾等全部流程节点。学习记录满足了热力图日历、统计概览、刷题记录时间线、面试历史列表与收藏夹管理等功能。项目作为纯前端 SPA，后端数据通过本地 Mock 完整模拟，在文档中明确标注了 Mock 策略与真实 API 切换指南。

## 6. 美观度

项目遵循 Modern Editorial 设计理念，以深海军蓝为主色调搭配翡翠绿品牌色，形成专业而不沉闷的视觉风格。标题字体采用 Plus Jakarta Sans 提供辨识度，正文中文字体选用 Noto Sans SC 保证阅读舒适度。Element Plus 组件库经过主题色覆盖与圆角调整，与 Tailwind CSS 原子类协同工作。卡片式布局配合统一的圆角、阴影和间距规范，不同功能区域通过色彩和层级清晰区分。交互层面提供了卡片悬浮上浮动效、页面切换淡入淡出、进度条动画、暗色模式全局切换等反馈机制，整体视觉一致性良好。
